# Release Boundary / 开源边界

## Public / 可以公开

- PARC retrieval-only routing source;
- the frozen PARC selector model and sibling manifest, with SHA256 checksums;
- route names, feature dimensions, and policy constants;
- prediction-free adapters and full-scope schema checks for the four families;
- score-only summaries;
- schema checks and deterministic self-tests;
- environment and reproduction documentation.

## Not redistributed / 不随仓库分发

- benchmark datasets and licensed model checkpoints;
- raw query/chunk/prompt/answer material;
- formal prediction and generation files;
- server logs, SSH keys, absolute paths, and temporary caches;
- paper source, figures, submission PDF;
- benchmark-specific licensing and copyright obligations.

## Not yet implemented in this release / 尚未纳入公开实现

- The audited materializer that creates Dense, safe and nine-route retrieval observations.
- Generator execution and official-scoring orchestration.
- Selector training entry point and its development-data protocol.
- Independent end-to-end regeneration of all paper results from this checkout.

These are code/evidence gaps, not merely missing model download links. The
adapters and prompt renderers are already included; they do not replace the
retrieval materializer or generator runner.

## Verification scope / 校验范围

The release verifier checks source/artifact hashes, synthetic unit tests,
the runtime self-test and a CPU routing example. CI repeats these checks on
clean checkouts and source archives. It does not run full benchmarks.

Before claiming full reproduction, publish the missing stages, use the pinned
upstream sources and licenses, run the complete paper inventory in a clean
environment, and record the exact code/data/model revisions. Keep generation
and scoring separated from routing and never substitute a positive-only subset.

The software is MIT licensed; benchmark licenses remain separate. The model
manifest's `FROZEN_FINAL_MODEL_NOT_FORMALLY_CONFIRMED` status is preserved as
the development-time freeze record, not rewritten as a later evaluation
claim. Published score summaries and a passing synthetic test do not prove
that all formal paper results have been regenerated by this repository.
