# Release Boundary / 开源边界

## Public / 可以公开

- PARC retrieval-only routing source;
- the frozen PARC selector model and sibling manifest, with SHA256 checksums;
- route names, feature dimensions, and policy constants;
- score-only summaries;
- schema checks and deterministic self-tests;
- environment and reproduction documentation.

## Private or pending approval / 暂不公开或需确认

- benchmark datasets and licensed model checkpoints;
- raw query/chunk/prompt/answer material;
- formal prediction and generation files;
- server logs, SSH keys, absolute paths, and temporary caches;
- paper source, figures, submission PDF;
- software license and copyright policy.

## Release gate / 正式发布前

Add public benchmark download and preprocessing instructions; provide clean
benchmark adapters and the downstream generation/scoring pipeline; run the
routing example and a full end-to-end replay in a clean environment; inspect
for credentials and private paths; choose a license; record the paper artifact
commit hash. The included manifest is a development-time frozen model record,
not a claim that the formal paper results are independently regenerated by this
repository.
