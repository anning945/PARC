# Release Boundary / 开源边界

## Public / 可以公开

- PARC retrieval-only routing source;
- the frozen PARC selector model and sibling manifest, with SHA256 checksums;
- route names, feature dimensions, and policy constants;
- prediction-free benchmark adapters and execution-inventory schema checks;
- current 35-task score-only summaries, fixed task manifest and aggregation script;
- schema checks and deterministic self-tests;
- development feature preparation from retrieval inputs and separate F1 labels;
- dual-view selector fitting and LOTO/LOFO final-policy selection;
- a separate, checksum-checked routing entry point for locally trained models;
- environment and reproduction documentation.
- complete Dense/BM25/RRF/XE retrieval materialization for all eleven methods;
- frozen routing, tokenizer-aware prompt reconstruction and prediction-blind packing;
- Qwen/Llama greedy generation with sharding and resume;
- pinned official-scorer validation, full-inventory scoring and aggregation.

## Not redistributed / 不随仓库分发

- benchmark datasets and licensed model checkpoints;
- raw query/chunk/prompt/answer material;
- formal prediction and generation files;
- server logs, SSH keys, absolute paths, and temporary caches;
- paper source, figures, submission PDF;
- benchmark-specific licensing and copyright obligations.

## Not bundled or not independently replayed / 未随仓库打包或尚未独立复跑

- End-to-end materialization of the development features and F1 labels.
- The earlier nested method-development study, distinct from final-policy selection.
- A newly completed independent end-to-end regeneration of all paper results
  from this checkout. The code is included; upstream data/models and a new
  full run are not bundled.

These items describe development-input dependencies and independent replay
status. All final evaluation pipeline stages are included.

## Verification scope / 校验范围

The release verifier checks source/artifact hashes, synthetic unit tests
(including selector fitting and group-held-out predictions), the runtime
self-test and a CPU routing example. CI repeats these checks on
clean checkouts and source archives. A separate CPU job tests real tiny local
embedding, reranking, and generation backends. Full benchmarks and component
experiments are separate runs with the upstream datasets and model weights.

An end-to-end run uses pinned upstream sources and records code, data, and
model revisions. Routing, generation, and scoring have separate stages.
The paper report aggregates the fixed 35-task manifest after the runner
validates its execution inventory. Scope and replay commands are in
[current paper results](current_paper_results.md).

The software is MIT licensed; benchmark licenses remain separate. The model
manifest's `FROZEN_FINAL_MODEL_NOT_FORMALLY_CONFIRMED` status is preserved as
the development-time freeze record, not rewritten as a later evaluation
claim. Published score summaries and a passing synthetic test do not prove
that all formal paper results have been regenerated by this repository.

See [selector training](selector_training.md) for runnable preparation,
fitting, policy selection and new-model routing. These scripts require
development retrieval observations and labels supplied by the user. New
fits are not paper artifacts and cannot be loaded by disabling the frozen
loader's integrity checks. This release does not claim a fresh full-data
retraining run or bit-identical reconstruction of the released model.
